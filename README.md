# 実務で使える量子プログラミングガイド

本リポジトリは、書籍『実務で使える量子プログラミングガイド』（著：浦田哲夫）に掲載された、Qiskitによる量子プログラム9本を収録しています。

## 内容

- QFTによる売上やログの周期検出
- Grover探索による広告条件・センサ相関の抽出
- 単一ビット測定による確率傾向の観測
- QAOAによるルート最適化（TSP）
- 振幅や干渉を活用した業務応用モデル

## 実行方法

- Python 3.10+
- Qiskit 必須  
  インストール: `pip install qiskit`

各 `.py` ファイルをターミナルまたはJupyter Notebookなどから実行してください。
